Real vulnerabilities discovered and reported through responsible disclosure.

OTP Authentication Bypass via Replay of Verification Response
Under Review
🏢 Canada Goose Inc. 📅 Oct 2026 🎯 HackerOne 🔒 Auth Bypass

The authentication flow is vulnerable to OTP verification bypass through replay of a previously successful verification response. An attacker can intercept a valid 200 OK response during a legitimate OTP submission, then replay it during a new login attempt with an invalid OTP — completely bypassing the second factor of authentication.

Authentication Bypass OTP Replay Broken Access Control Response Manipulation

IDOR on documentUploadFormData — S3 Upload Credential Exposure
P3
🏢 SEEK 📅 Oct 2026 🎯 Bugcrowd 🔒 IDOR

The viewer.documentUploadFormData(id: UUID!) GraphQL query generates S3 presigned upload credentials (including X-Amz-Security-Token) for any arbitrary UUID without verifying document ownership. Tested with all-zeros UUID — endpoint returned valid AWS credentials. Any authenticated user can generate upload credentials for any document ID.

IDOR GraphQL AWS S3 Credential Exposure
IDOR on /api/v2/users/{id} — User Profile Enumeration
Under Review
🏢 Vinted 📅 Oct 2026 🎯 Bugcrowd 🔒 IDOR

The endpoint returns full user profile data for any user ID without authorization checks. Exposes internal identifiers (anon_id), moderator/admin flags, verification status, privacy settings, and business account linkage. Allows full user enumeration by iterating through IDs.

IDOR User Enumeration Information Disclosure Privacy Violation
IDOR on seller_badges/achieved — Seller Badge Enumeration
Under Review
🏢 Vinted 📅 Oct 2026 🎯 Bugcrowd 🔒 IDOR

The endpoint returns a seller's earned badges (e.g., ACTIVE_LISTER) for any sellerID value without verifying authorization. Any authenticated user can enumerate badge data for every seller on the platform by iterating the sellerID parameter.
